Research software

ehrextract

Python package, Apache-2.0

Structured feature extraction from clinical notes. Bring notes as CSV, JSONL, JSON, XLSX, plain text or a pandas DataFrame, pick a built-in task or your own YAML, and pick a LoRA adapter, local weights or an API model. A results table comes back with one column per field.

Created by Chen Zhang (lead author) and Yibing Xia (co-author), supervised by Sanjay Mahant, MD (The Hospital for Sick Children) and Nathan Taback, PhD (University of Toronto). Research-grade software, not a medical device. pip install ehrextract

Other projects

contextd

Local-first RAG server with MCP, April 2026
Python, TypeScript, FastAPI, SQLite FTS5, LanceDB, BGE-M3

A local-first RAG server that ingests PDFs, Claude exports and git repos and exposes 7 MCP tools to any MCP client. Hybrid retrieval: BGE-M3 dense search (LanceDB) plus SQLite FTS5 BM25, fused by reciprocal rank fusion, with Claude Haiku reranking on by default when an Anthropic key is set.

Indexes stay on your machine; with an Anthropic key set, reranking sends the query and up to 50 candidate chunks to Anthropic. Not yet run end to end on the real embedding model.
