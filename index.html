ehrextract

Python package, Apache-2.0

Structured feature extraction from clinical notes. Bring notes as CSV, JSONL, JSON, XLSX, plain text or a DataFrame, pick a built-in task or your own YAML, and pick a LoRA adapter, local weights or an API model. A results table comes back with one column per field.

Created by Chen Zhang (lead author) and Yibing Xia (co-author), supervised by Sanjay Mahant, MD (The Hospital for Sick Children) and Nathan Taback, PhD (University of Toronto). Research-grade software, not a medical device. pip install ehrextract

contextd

Local-first RAG server with MCP, April 2026

Built contextd, a local-first RAG server that ingests PDFs, Claude exports and git repos and exposes 7 MCP tools to any MCP client (Claude Code, Codex CLI, Cursor). Implemented hybrid retrieval: BGE-M3 dense search (LanceDB) plus SQLite FTS5 BM25, fused by reciprocal rank fusion with an optional Claude Haiku reranker.

Indexes and queries stay on your machine; with an Anthropic key set, reranking sends the top candidate chunks to Anthropic.

autoTune

Autonomous LLM fine-tuning experiments, March 2026

Built autoTune, a framework that overlays an autotune/ directory onto ML repos so coding agents iterate on LLM finetuning through a CLI (suggest, reconcile, frontier). Designed DAG-structured experiment and checkpoint management with merge operations, NSGA-II Pareto ranking and DAG-UCB scoring instead of flat trials.

155 tests pass. Exercised on synthetic experiments; no published benchmark yet.

Stellaris AI Advisor

Game-state advisor, March 2026

Wrote a custom Clausewitz tokenizer and recursive-descent parser for Stellaris save files, feeding typed frozen dataclasses and a networkx game knowledge graph (tech DAG). Added a LightGBM LambdaMART colonization ranker evaluated with NDCG, plus Spearman-rho metrics and baselines for the RL value model.

Runs today as a rule-based Python library: parse a save, get ranked actions and alerts. Offline-RL training code (d3rlpy CQL/IQL) is in place; no trained model ships.
